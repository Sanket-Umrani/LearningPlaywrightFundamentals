# Taste

## Tooling & Workflow

- Prefers documentation (e.g. README) to be generated programmatically from source-of-truth files via an npm script rather than hand-maintained, so docs stay in sync with the code. Confidence: 0.6
- Prefers repetitive workflows automated as standalone `node <script>.js` CLI commands (e.g. a script that stages/commits/pushes changed files) rather than doing the steps manually. Confidence: 0.6
- Prioritizes shipping progress over credential hygiene in personal learning/sandbox repos: when warned that hard-coded test credentials would become public, chose to commit and push everything as-is rather than sanitize first. Confidence: 0.45
